# 财务岗位招聘数据洞察（智联招聘 2025.07–2026.09）

一个纯静态的可视化看板，用 GitHub Pages 托管。打开仓库对应的 Pages 地址即可查看，无需下载任何文件。

## 页面内容

1. **岗位数量趋势** —— 月度/每日岗位发布量与环比增长，可按岗位类别拆分
2. **城市分布与迁移** —— 月份滑块驱动的省份热力地图 + 城市气泡 + 当月 TOP 10 排行 + 头部城市趋势与排名变化（Bump 图）
3. **薪资水平趋势** —— 平均薪资/中位数/四分位区间、薪资档位占比变化，并按公司规模、学历、经验、城市对比
4. **学历要求占比趋势**
5. **经验要求占比趋势**（含「学历 × 经验」组合热度）
6. **公司规模** —— 岗位占比趋势 + 各规模平均薪资走势
7. **福利待遇** —— 19 个福利大类归并为「法定保障层 / 现金激励层 / 软性福利层」后的出现率趋势，以及控制变量后的薪资溢价
8. **技能标签** —— 33 个标签（证书资质/职能模块/企业性质/行业场景）的需求热度、趋势与薪资溢价分层
9. **岗位描述挖掘** —— 从 29.9 万条描述里提取 55 个关键词（工具与软件 / 证书与资质 / 职能与任务 / 软技能与工作条件 / 行业与场景），补齐「技能标签」字段缺失的工具类硬技能，并对比两种口径的覆盖率差异

## 数据口径

- 原始记录 299,901 条（按职位 URL 去重，无重复），时间跨度 2025-07-01 至 2026-09-30，覆盖 367 个城市。
- 薪资取区间中点折算为「元/月」，**忽略「·13 薪」等发薪月数**；日薪按 21.75 天/月、时薪按 8 小时/天折算；折算后低于 1,000 元或高于 200,000 元的不计入。可解析薪资 296,443 条（98.8%）。
- 所有占比均以当月岗位总数为分母。
- 「岗位福利」字段仅 32.8% 的岗位有填写，趋势解读需注意覆盖率波动。
- **薪资溢价估计**：把岗位按「城市组（TOP 30 城市 + 其他）× 学历（5 组）× 经验（7 类）× 公司规模（7 类）」切成 4,904 个单元格，只保留「有 / 无该特征」都 ≥3 条记录的单元格，在单元格内计算均值差并按调和均值样本量加权。该口径剔除了城市、学历、经验、规模的结构性差异，但仍是相关性而非因果。
- **岗位描述关键词**：55 个关键词全文匹配（英文不区分大小写），同一岗位同一关键词只计一次；不支持否定句识别（如「无需出差」会被计为命中）。

## 目录结构

```
index.html              页面结构
assets/css/app.css      样式
assets/js/app.js        图表逻辑（ECharts）
assets/js/echarts.min.js  本地内置的 ECharts 5.5.1（不依赖外部 CDN）
data/*.js               聚合后的数据（window.DATA["xxx"]）
```

## 本地更新数据

仓库只包含聚合后的数据文件。若原始 CSV 有更新，重新生成本目录下的 `data/*.js` 后提交即可，页面无需改动。
